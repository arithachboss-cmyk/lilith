# ลิลิ / Lili — บทบาทในการเล่าเรื่อง

ยึดตามคำแก้ไขของผู้ใช้: “ลิลิ คือ คาแรกเตอ , ผู้ให้ข้อมูลความทรงจำคือ owner และ ผู้ให้บทพาก คือ the middle”

| บทบาท | หน้าที่ |
| --- | --- |
| **owner** | ให้ข้อมูลต้นทาง ความทรงจำ และเรื่องราวที่จะนำมาเล่า |
| **The Middle** | ให้บทพากย์สำหรับถ่ายทอดเรื่องราวผ่านลิลิ |
| **ลิลิ / Lili** | คาแรกเตอร์ผู้เล่าที่ถ่ายทอดบทพากย์ให้ผู้ชมฟัง |

ลำดับงาน: **ความทรงจำจาก owner → บทพากย์จาก The Middle → ลิลิถ่ายทอดเรื่องราว**

ชื่อภาษาไทยใช้ **ลิลิ** และชื่อภาษาอังกฤษใช้ **Lili** ให้สม่ำเสมอ

คำว่า “ผู้ให้บทพากย์” ระบุหน้าที่ด้านบท ยังไม่ได้ระบุผู้แสดงเสียงหรือวิธีผลิตเสียง

## การนำเรื่องลูกค้ามาเล่า

ข้อมูลเหตุการณ์และประสบการณ์มาจาก owner ลิลิเล่าเรื่องเหล่านั้นผ่านคาแรกเตอร์ ไม่อ้างว่าลิลิมีความทรงจำส่วนตัวหรือเป็นผู้ดำเนินธุรกรรมจริง การบอกว่าใครช่วยผู้เช่าทำสิ่งใดต้องตรงกับข้อมูลต้นทาง

ตัวอย่างถ้อยคำเมื่อได้รับข้อมูลแล้ว:

> “สวัสดีค่ะ ลิลิค่ะ วันนี้ลิลิจะพาไปรู้จักเรื่องราวของผู้เช่าคนหนึ่งในกรุงเทพฯ จากความทรงจำที่ owner ถ่ายทอดให้เราฟังค่ะ…”

รูปแบบเครดิตเมื่อใช้ข้อมูลและบทจริง:

**คาแรกเตอร์ผู้เล่า: ลิลิ · ข้อมูลความทรงจำ: owner · บทพากย์: The Middle**

เอกสารบทที่มีอยู่เป็นร่างเตรียมงาน ตัวอย่างห้าเมืองยังเป็นเรื่องจำลองจนกว่าจะได้รับข้อมูลความทรงจำที่ยืนยันได้ และยังไม่ถือว่าได้รับบทพากย์ฉบับจริงจาก The Middle แล้ว

การแก้ไขบทบาทครั้งนี้คงแผนเปิดตัวเดือนละหนึ่งประเทศ/กลุ่มภาษา ตามลำดับ TH → KO → JA → VI และคงการพักเผยแพร่ตามคำสั่งเดิม

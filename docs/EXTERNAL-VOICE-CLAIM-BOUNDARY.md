# ขอบเขตคำพูดสำหรับเสียงจากภายนอก

**ใช้กับ:** อินฟลูเอนเซอร์ · KOL · affiliate · ตัวแทนขาย · เอเจนซี · พนักงานที่โพสต์ในนามตัวเอง
· ทุกคนที่ได้รับเงิน ของ ส่วนลด หรือค่าคอมมิชชันจากเรา แล้วพูดถึงเราในที่สาธารณะ

**สองธุรกิจ สองชุดกฎ** — ACS (asiancoding.com) อยู่ใน §3 · Lilith / The Middle Property อยู่ใน §4
**ห้ามใช้ข้ามกัน** เพราะข้อจำกัดคนละเรื่องโดยสิ้นเชิง

เอกสารนี้เป็นขอบเขตคำพูด ไม่ใช่แผนการตลาด และไม่ใช่การอนุมัติให้จ้างใคร


> **หมายเหตุเรื่องด่านตรวจกับไฟล์นี้** — เอกสารนี้ยกคำและประโยคที่ถูกกั้นมาเขียนตรง ๆ
> เพราะหน้าที่ของมันคือบอกคนนอกว่า **ห้ามพูดอะไร** `node acs-seo/tools/redact.mjs docs/EXTERNAL-VOICE-CLAIM-BOUNDARY.md`
> จึงฟ้อง 12 รายการ ซึ่งทุกรายการเป็น **การอ้างอิงเพื่อห้าม ไม่ใช่การเขียน claim**
> ตั้งใจไม่แก้ เพราะ brief ที่เลี่ยงคำจนบอกไม่ได้ว่าห้ามพูดว่า "อันดับ 1" คือ brief ที่ใช้ไม่ได้
> `validate.mjs` สแกนเฉพาะไฟล์ที่ขึ้นเว็บจริง ไฟล์นี้ไม่อยู่ในนั้นและไม่มีวันขึ้นเว็บ
> **ฉบับที่ส่งให้อินฟลูเอนเซอร์จริงคือไฟล์นี้ทั้งฉบับ** — ไม่ต้องตัดอะไรออก

## 1 · หลักการเดียวที่ทุกข้อในเอกสารนี้ไหลมาจาก

> **คนนอกพูดแทนเราไม่ได้ในสิ่งที่เราเองพูดไม่ได้**

การจ่ายเงินให้คนอื่นพูดประโยคหนึ่ง ไม่ได้ย้ายภาระการพิสูจน์ไปที่เขา
มันย้ายแค่ *ภาพว่าเป็นความเห็นอิสระ* ซึ่งเป็นการย้ายที่แย่ที่สุดในสองทาง:
เมื่อมีคนท้วง เราคือผู้โฆษณา ส่วนเขาคือพยานที่เราจ่ายเงิน

ดังนั้นทะเบียน `acs-seo/data/claims.json` ที่บังคับกับหน้าเว็บของเราอยู่แล้ว
**บังคับกับคำพูดของอินฟลูเอนเซอร์ด้วยทุกตัวอักษร** ไม่มีข้อยกเว้น ไม่มีเวอร์ชันผ่อนปรน

มีสิ่งเดียวที่คนนอกทำได้และเว็บเราทำไม่ได้ — **การเล่าประสบการณ์ของตัวเอง** (§5)
นั่นคือคุณค่าทั้งหมดของช่องทางนี้ และเป็นเหตุผลเดียวที่ควรจ่ายเงิน

## 2 · การเปิดเผยว่าจ้าง — บังคับ ไม่มีข้อยกเว้น

สคบ. ระบุว่าผู้รีวิวที่ได้รับค่าตอบแทนต้องเปิดเผย มิฉะนั้นเข้าข่ายทำให้ผู้บริโภค
เข้าใจผิดว่าเป็นประสบการณ์ส่วนตัวล้วน ๆ ทั้งที่เป็นการโฆษณา

| ต้องมี | รายละเอียด |
|---|---|
| ข้อความเปิดเผย | `#โฆษณา` หรือ `#ได้รับสินค้าฟรี` หรือ `#ค่าตอบแทนจาก...` ตามความจริง |
| ตำแหน่ง | **อยู่ในสามบรรทัดแรก** ของแคปชัน ไม่ใช่ท้ายแท็กรวม และไม่ซ่อนหลังปุ่ม "ดูเพิ่มเติม" |
| วิดีโอ | พูดออกเสียงหรือขึ้นข้อความบนจอในช่วง 5 วินาทีแรก |
| ของฟรีที่ไม่มีเงินสด | **ยังต้องเปิดเผย** — "ได้รับมารีวิว" ก็คือค่าตอบแทน |

การซ่อนการเปิดเผยเพื่อให้ดูเป็นธรรมชาติ คือสิ่งที่กฎข้อนี้ห้ามพอดี **ห้ามขอให้ใครทำ**

## 3 · ACS — บาร์โค้ด RFID ฉลาก คลังสินค้า

### 3.1 พูดได้ทันที (เขียวสนิท)

หลักการทั่วไปของเทคโนโลยี ไม่อ้างตัวเลข ไม่อ้างผลงาน ACS — ตรงกับ `SAFE_WORDING`

- การใช้บาร์โค้ดแทนการคีย์มือ ลดโอกาสพิมพ์ผิด
- บาร์โค้ดบอกว่า "มีของสิ่งนั้นอยู่" ไม่ได้บอกว่ามีกี่ชิ้น — การนับสต็อกยังต้องเป็นกระบวนการ
- RFID อ่านได้โดยไม่ต้องเล็งและอ่านได้ทีละหลายชิ้น บาร์โค้ดต้องเห็นเส้น
- ฉลากที่ใช้ในคลังเย็นกับในสำนักงานเป็นวัสดุคนละแบบ
- การเลือกเครื่องอ่านควรเริ่มจากสภาพหน้างาน ไม่ใช่เริ่มจากยี่ห้อ
- ACS ขายและติดตั้งระบบจัดเก็บข้อมูลด้วยบาร์โค้ดและ RFID

ทั้งหกข้อมีฉบับเต็มพร้อมบริบทใน `acs-seo/content-packages/` ให้อินฟลูเอนเซอร์หยิบไปใช้ได้เลย

### 3.2 พูดได้เมื่อมีเอกสาร และต้องอ้างเอกสารนั้นในโพสต์

ต้องมี datasheet / GS1 / เอกสาร ACS สถานะ `SUPPLIED` เท่านั้น — `EVIDENCE_REQUIRED`

| เรื่อง | claim | เงื่อนไขที่ลืมไม่ได้ |
|---|---|---|
| ระยะอ่าน · ความเร็ว · ความแม่นยำ | `CLM-E-001/002/003` | **ต้องมีเงื่อนไขการวัดติดมาด้วย** ตัวเลขจาก datasheet ที่ตัดเงื่อนไขทิ้ง กลายเป็นคำโกหกทันที |
| อุณหภูมิ · สารเคมี · UV · น้ำ ของฉลาก | `CLM-E-004/005` | ต้องเป็นรหัสวัสดุที่ ACS ขายจริง ไม่ใช่วัสดุทั่วไป |
| GTIN · GS1-128 · Application Identifier | `CLM-E-006` | อ้างฉบับและหัวข้อของ GS1 General Specifications |
| IP rating · มาตรฐานการตกกระแทก | `CLM-E-007` | |
| ความเข้ากันได้กับ OS หรือซอฟต์แวร์ | `CLM-E-008` | |
| ESG · ความยั่งยืน | `CLM-E-009` | ห้ามพูดกว้าง ๆ ว่า "เป็นมิตรกับสิ่งแวดล้อม" |
| ความสามารถของเครื่องมือ AI ของ ACS | `CLM-E-010` | |
| **การเอ่ยชื่อผู้ผลิต** | `CLM-E-011` | ใช้ได้เฉพาะเป็นการอ้างสเปกจากเอกสารทางการ · **ห้ามใช้ในบริบทที่สื่อว่ามีความสัมพันธ์ทางธุรกิจ** |

ข้อสุดท้ายพลาดง่ายที่สุด ประโยคอย่าง *"ACS เอาของ Honeywell มาให้ลองด้วย"*
สื่อถึงความสัมพันธ์ทางธุรกิจโดยที่ผู้พูดไม่ได้ตั้งใจ และชนกับ §3.3 ข้อแรกเต็ม ๆ

### 3.3 ต้องให้ ACS ยืนยันก่อน และบางข้อ ACS ยืนยันเองไม่ได้

| เรื่อง | claim | **ใครเป็นคนปิด** |
|---|---|---|
| ราคา | `CLM-O-001` | ACS — และต้องมี **วันที่มีผล** ติดมาด้วย |
| รายการ/รุ่นที่ขายจริง | `CLM-O-002` | ACS |
| **สถานะตัวแทนจำหน่าย/พาร์ทเนอร์ของแบรนด์** | `CLM-O-003` | **แบรนด์นั้น ไม่ใช่ ACS** — ต้องมีหนังสือรับรองพร้อมวันที่ |
| **เคสลูกค้า / อุตสาหกรรมที่เคยติดตั้ง / ผลลัพธ์ที่ลูกค้าได้** | `CLM-O-004` | **ลูกค้ารายนั้น** — ACS อนุมัติประโยคไม่ได้ทำให้ผ่าน และ **ปิดชื่อก็ไม่ช่วย** |
| SLA · ระยะส่งมอบ · บริการหลังการขาย | `CLM-O-005/010` | ACS |
| จำนวนปี · จำนวนลูกค้า · ขนาดทีม | `CLM-O-006/008` | ACS |
| พื้นที่ให้บริการ | `CLM-O-007` | ACS |
| สต็อก · ความพร้อมของสินค้า | `CLM-O-009` | ACS — **และหมดอายุเร็วกว่าราคา** "มีสต็อก" จริงแค่เท่าที่ของยังอยู่ ซึ่งอาจเป็นหลักชั่วโมง |

### 3.4 ห้ามพูด — ไม่มีเงื่อนไขปลดล็อก

| ห้าม | claim | เหตุผล |
|---|---|---|
| ACS เป็นผู้นำ / อันดับ 1 / เจ้าตลาด / รายใหญ่ที่สุด / ชั้นนำ | `CLM-B-005` | **ไม่มีอะไรปิดได้** ไม่มีแหล่งอ้างอิงที่ตรวจสอบได้ |
| ยี่ห้อไหนดีที่สุด / เหนือกว่าคู่แข่ง | `CLM-B-004` | **ไม่ปลดล็อกถาวร** — ให้ใช้เกณฑ์ตัดสินใจแทน |
| รับประกันผลเป็นตัวเลข เช่น คืนทุนใน X เดือน ประหยัด X% | `CLM-B-006` | ต้องมีเคสลูกค้าที่ยืนยันได้ |
| ทนทุกสภาพแวดล้อม / กันน้ำ 100% / ทนสารเคมีทุกชนิด | `CLM-B-002` | |
| ตัวเลขความแม่นยำ 65-70% → 95%+ | `CLM-B-001` | Owner สั่งลบแล้ว |
| ราคาเฉพาะเจาะจงโดยไม่มีราคาพร้อมวันที่ | `CLM-B-003` | |

> **กับดักที่ต้องบอกอินฟลูเอนเซอร์ตรง ๆ:** การเลี่ยงไปพูดว่า *"ร้านสะดวกซื้อรายใหญ่ที่สุดในประเทศก็ใช้"*
> **ไม่ได้ช่วยเลย** — มันระบุตัวบริษัทเดียวกันกับการเอ่ยชื่อ และยังเพิ่มซูเปอร์ลาทีฟที่ห้ามอยู่แล้ว
> เป็นการชน `CLM-O-004` และ `CLM-B-005` พร้อมกัน

### 3.5 ความจริงเรื่องช่องทางที่ต้องพูดก่อนเสียเงิน

คนซื้อของ ACS คือผู้จัดการคลัง ฝ่ายไอที ฝ่ายจัดซื้อ ผู้จัดการร้าน
**อินฟลูเอนเซอร์สายผู้บริโภคเข้าไม่ถึงคนกลุ่มนี้** ยอดวิวไม่แปลงเป็นใบเสนอราคา

ช่องทางที่ตรงกับผู้ซื้อจริงคือ: ผู้เชี่ยวชาญสายซัพพลายเชนบน LinkedIn · สื่อ/เพจอุตสาหกรรมและโลจิสติกส์
· งานแสดงสินค้า · เนื้อหาสาธิตหน้างานจริง — ซึ่งอย่างหลังชน `CLM-O-004` ถ้ามีลูกค้าจริงอยู่ในเฟรม

## 4 · Lilith / The Middle Property — เอเจนต์อสังหาฯ

ความเสี่ยงคนละชุดกับ ACS โดยสิ้นเชิง ที่นี่อันตรายไม่ได้อยู่ที่สเปกสินค้า
แต่อยู่ที่ **การรับประกันผลตอบแทน · ข้อมูลส่วนบุคคล · และการทำให้ของตัวอย่างดูเหมือนของจริง**

### 4.1 พูดได้

- อธิบายว่าบริการทำงานอย่างไร: บอกความต้องการ → ทีมงานคัดให้ → นัดดู
- อธิบายว่าทำไมการบอกงบและทำเลตั้งแต่ต้นถึงช่วยให้ได้ตัวเลือกที่ตรงกว่า
- เล่าประสบการณ์การใช้งานของตัวเองตาม §5
- บอกว่าติดต่ออย่างไร

### 4.2 ห้ามพูด — อสังหาฯ

| ห้าม | เหตุผล |
|---|---|
| **รับประกันผลตอบแทน ค่าเช่า yield หรือราคาที่จะขึ้น** | เป็นการรับประกันผลลัพธ์ทางการเงิน · ตัวสินค้าเองมีขั้นตอน "แจ้งว่าไม่รับประกันผล" อยู่ในระบบแล้ว การให้คนนอกพูดสวนทางคือการล้มระบบของตัวเอง |
| **"ห้องนี้ปล่อยเช่าได้แน่นอน" / "ขายต่อได้กำไรแน่"** | เช่นเดียวกัน |
| **ค่าธรรมเนียม/ค่านายหน้าเป็นตัวเลข** | ฐานคิดและผู้จ่ายยังเป็น **ข้อที่เจ้าของยังไม่ตัดสิน** ห้ามพูดจนกว่าจะตัดสิน |
| **นำเสนอยูนิตตัวอย่างว่าเป็นของจริง** | หน้าเว็บปัจจุบันติดป้าย `SAMPLE DATA` ชัดเจน · การให้อินฟลูเอนเซอร์พูดถึงมันเหมือนเป็นสต็อกจริง คือการสร้างรายการที่ไม่มีอยู่ |
| **ถ่ายติดผู้เช่า เจ้าของ เพื่อนบ้าน เลขห้อง ป้ายทะเบียน หรือเอกสารสิทธิ์** | PDPA — ต้องมีความยินยอมของบุคคลนั้น ไม่ใช่ของเรา |
| **ถ่ายในห้อง/โครงการโดยไม่ได้รับอนุญาตจากเจ้าของและนิติบุคคล** | |
| **"ถูกที่สุด" / "เอเจนต์อันดับ 1" / "ดีที่สุดในกรุงเทพ"** | ซูเปอร์ลาทีฟ · เหตุผลเดียวกับ `CLM-B-005` |

### 4.3 ข้อที่ต้องให้เจ้าของยืนยันก่อน

จำนวนดีลที่ปิดได้ · จำนวนยูนิตในมือ · รายชื่อโครงการที่ร่วมงานด้วย · ขนาดทีม · จำนวนปี
· พื้นที่ให้บริการ — **ทั้งหมดยังไม่มีเอกสารยืนยันในระบบ ณ วันที่เขียน**

## 5 · สิ่งเดียวที่คนนอกพูดได้แต่เว็บเราพูดไม่ได้

**ประสบการณ์ตรงของผู้พูดเอง** นี่คือเหตุผลทั้งหมดที่ควรจ่ายเงินให้ช่องทางนี้

| ✅ พูดได้ | ❌ กลายเป็น claim ทันทีเมื่อ |
|---|---|
| "ลองสแกนเองแล้วติดง่ายกว่าที่คิด" | ใส่ตัวเลข → `CLM-E-003` |
| "ถือทั้งวันแล้วมือไม่ล้าเท่าตัวเก่าที่เคยใช้" | เทียบยี่ห้อ → `CLM-B-004` |
| "คุยกับทีมแล้วตอบเร็ว" | แปลงเป็น SLA → `CLM-O-005` |
| "ผมได้ห้องที่ตรงกับที่บอกไว้" | "ทุกคนจะได้แบบนี้" → รับประกันผล |

**เส้นแบ่ง:** ประสบการณ์เป็นเอกพจน์และเป็นอดีต — *ฉัน เมื่อวานนี้ กับเครื่องนี้*
ทันทีที่ประโยคกลายเป็นพหูพจน์หรืออนาคต — *ทุกคน จะ ได้เสมอ* — มันเลิกเป็นประสบการณ์และกลายเป็น claim

**ห้ามเขียนสคริปต์ให้เขาแล้วบอกว่าเป็นความเห็นของเขา** ให้ขอบเขตกับข้อเท็จจริง ไม่ใช่ให้ประโยค
ถ้าเราเขียนประโยคให้ มันคือคำพูดของเรา และต้องผ่านด่านเดียวกับหน้าเว็บทุกด่าน

---

## 6 · ข้อที่ต้องอยู่ในสัญญาจ้าง

1. เปิดเผยว่าได้รับค่าตอบแทน ตาม §2 — **ผิดข้อนี้ = ผิดสัญญา ไม่จ่าย**
2. ยอมรับขอบเขตคำพูดฉบับนี้เป็นเอกสารแนบท้าย
3. ส่งเนื้อหาให้ตรวจก่อนโพสต์ตาม §7
4. ห้ามพูดแทนแบรนด์ผู้ผลิตใด ๆ ว่าเรามีความสัมพันธ์ทางธุรกิจ (`CLM-O-003`)
5. ห้ามเอ่ยถึงลูกค้ารายใดของเรา แม้ปิดชื่อ (`CLM-O-004`)
6. ยินยอมแก้หรือลบภายใน 24 ชม. เมื่อเราแจ้งว่าเนื้อหาชน claim
7. เก็บโพสต์ไว้ขั้นต่ำตามที่ตกลง ห้ามลบเงียบ เพราะหลักฐานการเปิดเผยต้องตรวจสอบย้อนได้
8. **ห้ามใช้ AI สร้างภาพสินค้าหรือห้องที่ไม่มีอยู่จริง**

## 7 · ก่อนโพสต์ — ตรวจ 6 ข้อ

1. มีข้อความเปิดเผยในสามบรรทัดแรก / 5 วินาทีแรกหรือยัง
2. มีตัวเลขไหม → ตัวเลขนั้นมาจากเอกสารที่ไหน และ**เงื่อนไขการวัดติดมาด้วยหรือเปล่า**
3. มีการเทียบยี่ห้อหรือคำว่า "ที่สุด" ไหม → ตัดออก
4. มีชื่อลูกค้า โลโก้ หรือคำบรรยายที่ระบุตัวลูกค้าได้ไหม → ตัดออก แม้ปิดชื่อแล้ว
5. มีคำสัญญาถึงอนาคตหรือผลตอบแทนไหม → ตัดออก
6. มีคนอื่นอยู่ในเฟรมหรือข้อมูลที่ระบุตัวบุคคลได้ไหม → มีความยินยอมหรือยัง

ข้อ 2 กับ 4 คือสองข้อที่พลาดบ่อยที่สุด และเป็นสองข้อที่เสียหายแพงที่สุด

## 8 · เมื่อมีคนพูดเกินขอบเขตไปแล้ว

1. **ห้ามแชร์ซ้ำ ห้ามกดไลก์ ห้ามคอมเมนต์ขอบคุณ** — การรับเอาคำพูดนั้นทำให้เป็นคำพูดของเรา
2. แจ้งให้แก้หรือลบภายใน 24 ชม. ตาม §6 ข้อ 6
3. บันทึกไว้ว่าเกิดอะไร แก้อย่างไร เพื่อให้มีร่องรอยว่าเราไม่ได้ปล่อย
4. ถ้าเป็นข้อใน §3.4 หรือ §4.2 → ยุติความร่วมมือ

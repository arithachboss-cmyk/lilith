# Cannibalization Gate

ต้องผ่าน gate นี้ **ก่อนเขียน** ทุกแพ็กเกจ ไม่ใช่ตรวจตอนจบ

สถานะปัจจุบัน: **BLOCKED_ON_SOURCE** — ยังไม่มี page inventory (`SRC-WEB-002`) จึงยังตัดสินไม่ได้

## ขั้นตอน

1. ระบุ **canonical intent** ของแพ็กเกจเป็นหนึ่งประโยค: หน้านี้ตอบอะไร และจงใจ **ไม่** ตอบอะไร
2. ค้นหน้าเดิมใน `data/page_inventory.json` ที่ intent ใกล้เคียง (เทียบ `primary_intent` + `page_type`)
3. ถ้าไม่มีหน้าใกล้เคียง → `action = NEW` ผ่าน gate
4. ถ้ามี ให้เลือกหนึ่งในสามทาง แล้วบันทึกใน `brief.md`:

| ทางเลือก | ใช้เมื่อ | ผลที่ต้องทำ |
|---|---|---|
| **ENRICH** หน้าเดิม | intent เดียวกัน หน้าเดิมมีสิทธิ์จัดอันดับอยู่แล้ว | `action = ENRICH`, `target_url` = URL เดิม, ห้ามสร้าง URL ใหม่ |
| **NEW + canonical intent** | intent แยกกันได้จริงและอธิบายเป็นประโยคได้ | `action = NEW`, เขียน canonical intent ของทั้งสองหน้าใหม่ให้ไม่ทับกัน, วาง internal link ระหว่างกัน |
| **HOLD** | แยก intent ไม่ออก หรือต้องให้ Owner ตัดสิน | `action = HOLD`, `board_status = HOLD`, หยุดเขียนทันที |

5. บันทึกผู้ตัดสินและวันที่ใน `brief.md` ทุกครั้ง

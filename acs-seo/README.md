# ACS SEO Package Factory — Governance Pack

Governance scaffolding for ACS SEO content production. Nothing here is publishable content
and nothing authorises a publish.

| File | What it is |
|---|---|
| `00_SOURCE_PACK_INDEX.md` | Source stream status + the real 82-URL live page inventory, classified, with cannibalisation clusters |
| `01_CLAIM_REGISTER.md` | The four claim classes, binding Owner decisions, site-derived claim rows, forbidden-words list |
| `02_PACKAGE_STATUS_BOARD.md` | PASS / REVISE / HOLD / BLOCKED for all 19 packages |
| `03_QA_CHECKLIST.md` | Tiered QA — mechanical for all, deep review only where it matters |
| `04_OWNER_REPORT.md` | One page, four decisions |
| `templates/` | The mandatory 7-file package template |

## Standing rules

1. Every package stays `DRAFT_PENDING_REVIEW` until the Owner approves it.
2. No publish, no deploy, no DNS change, no traffic, no real claim without evidence.
3. The cannibalisation gate runs **before** writing, never after.
4. No package is SEO-ready until the SSR/prerender rendering gate clears.
5. Nothing in this pack is invented. Missing sources are recorded as missing.

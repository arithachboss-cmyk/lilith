## บทเรียนใหม่ — comment ในไฟล์ที่ขึ้นเว็บก็ถูกสแกน

ร่างแรกเขียนใน comment ส่วนหัวว่า *"ไม่มีการอ้างเคสลูกค้า"* ซึ่งเป็นการ**ประกาศว่าไม่ได้ทำ**
แต่ `validate.mjs` สแกน `article.md` ทั้งไฟล์รวม comment และกฎ `FW-O-002` จับคำว่า "เคสลูกค้า"
ด้วย severity `OWNER` ซึ่งทำให้ **FAIL จริง** ไม่ใช่แค่รายงาน

เรียบเรียงเป็น *"ไม่อ้างถึงงานที่เคยทำให้ผู้ใด"* แล้วผ่าน

**ไม่ได้เสนอให้ยกเว้น comment จากการสแกน** — comment อยู่ในไฟล์ที่ขึ้นเว็บ ใครก็เปิดดู source ได้
และการยกเว้นจะเปิดช่องให้ข้อความที่ถูกกั้นย้ายไปอยู่ใน comment แทน

**บทเรียนที่ใช้ต่อ** — เขียน comment โดยเลี่ยงคำที่เป็นตัวกฎเอง ต่างจาก `claim_register.md`
และ round log ซึ่งไม่ขึ้นเว็บ จึงยกข้อความต้องห้ามมาอ้างอิงได้
